Повышение в звании

Официальные критерии, скриншоты-доказательства и готовый BBCode-рапорт для форума — в одном месте.

Важно! При наличии дисциплинарного взыскания (устного выговора/письменного выговора), а также использовании подтверждающей документации находясь в предшествующей должности, в присвоении очередного воинского звания автоматически будет отказано.

Выберите подразделение
  1. Подразделение и званиеПоявятся официальные критерии на следующее звание.
  2. СкриншотыПеретащите, выберите или вставьте Ctrl+V в нужный пункт.
  3. Image ChestОдна кнопка — по одной ссылке на каждый критерий.
  4. РапортBBCode собирается сам, остаётся скопировать.

Настройки

Image Chest

Токен нужен, чтобы загружать скриншоты. Хранится только в этом браузере и уходит только на api.imgchest.com.

Проверка…
Где взять токен
  1. Откройте imgchest.com/settings/api.
  2. В блоке Personal Access Tokens нажмите Generate New Token.
  3. Скопируйте ключ, вставьте сюда и нажмите Сохранить.

1 критерий = 1 пост · до 20 фото в посте · приватность hidden (только по ссылке)

Загрузить в Image Chest?

На каждый критерий — отдельный пост и одна ссылка вида imgchest.com/p/…

Личные документы

Файлы могут содержать персональные данные и уйдут во внешний сервис Image Chest.

  • Приватность hidden — доступ только по прямой ссылке, в каталоге не появится.
  • Сами файлы в браузере не сохраняются — только ссылка на пост.
